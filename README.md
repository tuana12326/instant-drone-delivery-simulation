# Anlık Drone Teslimat Simülasyonu

Python ile geliştirilmiş bir mini simülasyon projesi. Bu proje, droneları siparişlere otomatik olarak atayan ve komut doğrulama sistemi içeren bir simülasyonu içerir.

## Dosya Yapısı

- `src/drone.py` → Drone sınıfı
- `src/order.py` → Order sınıfı
- `src/dispatcher.py` → Drone atama algoritması
- `src/security.py` → Komut doğrulama
- `src/main.py` → Ana simülasyon dosyası

## Kullanım

Projeyi çalıştırmak için:

```bash
python src/main.py
